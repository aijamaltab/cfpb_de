# Карточки источников

Шесть источников: два API (CFPB с двумя контурами, FDIC), три CSV (ставка ФРС FRED, два справочника) и «база сайта» для CDC. Здесь технические контракты; паспорт в формате ментора: `passport.md`. Пустое место = не проверено.

## 1. CFPB Consumer Complaint Database API

| Вопрос | Ответ |
|---|---|
| Откуда и как достать | GET `https://www.consumerfinance.gov/data-research/consumer-complaints/search/api/v1/`, ключа нет. Параметры: size, sort, date_received_min, date_received_max, no_aggs; листаем курсором search_after (`frm` игнорируется); product принимает одно значение за запрос |
| Что отдаёт | JSON: `hits.total.value`, `hits.hits[]._source` с 15 полями, вложенности нет, `aggregations` отключаем (no_aggs) |
| Как меняется | новые жалобы каждый день; у старых меняется `company_response` и `company_public_response`; **жалобы за прошлые дни добавляются задним числом (публикуются после отправки компании), иногда снимаются** |
| Сколько | банковский контур: 855 110 за 1096 дней, в среднем около 780 в день; контур бюро: 1 909 762 за 92 дня, около 21 тыс. в день |
| Что ломается | WAF отдаёт 403 для python-requests (поэтому HTTP идёт через curl, `ingestion/cfpb_http.py`); пустой ответ при 200; смена названий полей; дата в ответе не равна запрошенной |
| Роль | событие (по дням, `date_received`) + сущность (статус) |
| Режим загрузки | delete + insert по `_ds` |
| Лицензия | CC0 |
| Версия API | v1 в адресе |
| Контракт | колонки `sql/02_stg_cfpb.sql`; новое или пропавшее поле = ошибка загрузки |

Контуры:
- **Банки** (8 продуктов, написание как в данных): Credit card; Checking or savings account; Mortgage; Money transfer, virtual currency, or money service; Vehicle loan or lease; Payday loan, title loan, personal loan, or advance loan; Student loan; Prepaid card. Источник правды: `PRODUCTS` в `ingestion/load_cfpb.py`. Окно 1 окт 2023 — 30 сен 2026.
- **Бюро и коллекторы**: два продукта, Credit reporting or other personal consumer reports и Debt collection (`BUREAU_PRODUCTS` в `ingestion/bureau_pipeline.py`). Окно 1 июл — 30 сен 2026. Пересечения с банковским контуром нет (проверка в `sql/13_bureau_checks.sql`).

Проверено на реальных данных: покрытие 1096 дней без дыр; сверка с API по дням; названия продуктов в 2023–2024 годах сходятся (иначе загрузка падала бы).

Особенность: позднее появление жалоб. Сверка нашла 57 банковских дней, где загруженное расходилось с API; `cfpb_resync` перезагрузил их, добавилось 854 жалобы. Контур бюро: 0 расхождений. Свежие недели недосчитаны.

## 2. FDIC `/financials` (квартальные показатели банков США)

| Вопрос | Ответ |
|---|---|
| Откуда и как достать | GET `https://api.fdic.gov/banks/financials`, ключа нет. Фильтр `REPDTE:<конец квартала>`, постраничная выдача по 5000 |
| Что отдаёт | по банку и кварталу: CERT, REPDTE, ASSET (активы), DEP (депозиты), NETINC, ROA, ROE, EQ, NUMEMP. **Суммы в тысячах USD**, NETINC накопительно с начала года |
| Как меняется | раз в квартал появляется новый квартал. Пересмотр старых отчётов не проверялся, поэтому каждый запуск перезагружает все кварталы |
| Сколько | 14 кварталов (Q1 2023 — Q2 2026), около 4,5 тыс. банков на квартал, около 63,8 тыс. строк |
| Что ломается | последний квартал ещё не опубликован (допустим только в конце ряда); квартал с малым числом банков; расхождение с `meta.total` |
| Режим загрузки | truncate + reload целиком (маленький справочный источник) |
| Проверки | сверка с `meta.total` по кварталу; минимум 3000 банков в квартале; нет пропущенных кварталов; даты — концы кварталов; активы не отрицательные |
| Роль | справочник размера банка (измерение для витрины) |

Связь с жалобами: `data/ref/company_bank_map.csv` (24 компании → 25 банков) загружается в `ods_company_bank`. Покрывает около 43% жалоб банковского контура:
остальные относятся к финтеху, бюро, сервисерам и кредитным союзам, которых в FDIC нет. Витрина `dm_bank_size_quarter` (11 кварталов, 264 строки)
показывает жалобы на 1 млрд USD активов; метрика грубая.

## 3. Ставка ФРС FRED DFF (CSV, событие с датой)
| Вопрос | Ответ |
|---|---|
| Откуда и как достать | файл `data/fred/DFF.csv`; скачивается один раз: `curl -sS -m 60 "https://fred.stlouisfed.org/graph/fredgraph.csv?id=DFF&cosd=2023-10-01" -o data/fred/DFF.csv`. Ключа нет. Проверено 22.10.2026: сервер Airflow достаёт этот адрес, заголовок `observation_date,DFF`, строки идут каждый календарный день |
| Контракт | две колонки: `observation_date` (YYYY-MM-DD), `DFF` (число, % годовых; `.` = нет значения → NULL в ods) |
| Режим загрузки | за `ds` берётся одна строка файла: delete + insert по `_ds`. Если файл не дотягивает до `ds`, задача пробует докачать ряд (`refresh_fred_file` в `ingestion/csv_sources.py`). FRED выходит с задержкой 1–3 дня, поэтому за самые свежие дни строки ещё нет: в `stg_fred_dff` пусто, а в `ods_fred_dff` переносится последняя известная ставка с пометкой `is_carried = true` (не дальше 14 дней от конца ряда). Повторный запуск даты после выхода ряда подставит настоящее значение |
| Проверки | заголовок файла; дата не раньше начала файла; дыра внутри ряда и отставание ряда больше 14 дней: ошибка; в ods ровно одна строка за `ds` |
| Роль | событие с датой; колонка `fed_funds_rate` витрины `dm_complaints_daily` |

## 5. «База сайта»: `tabyldieva.complaint_cases` (источник CDC)
Имитация системы обработки обращений: PK `complaint_id`, `status` (`in_progress`, `closed_explanation`, `closed_relief`, `closed_other`), `updated_at`. Стартовые строки — обращения последних 30 дней из `ods_complaints`.
Изменения читает Debezium из журнала WAL (`REPLICA IDENTITY FULL`, публикация `dbz_tabyldieva`, слот `dbz_tabyldieva`), приёмник пишет `tabyldieva_ods.ods_complaint_cases`. Подробно: `cdc/README.md`.

## Отложенные и отброшенные источники
- Население США (Census): сайт заблокирован для сервера и браузера, к тому же данные годовые, а жалобы помесячные, поэтому источник отброшен.
- FDIC `/institutions` (справочник банков) и открытые данные Центрального банка Узбекистана (cbu.uz, небольшие наборы без периода): пробовались, из проекта убраны.
- Бразилия (BCB, рейтинг жалоб на банки, квартальные CSV): код и DAG написаны отдельным пакетом (`bcb_pkg.zip`), в репозиторий не установлены.
  Запасной вариант, если ментор потребует третий источник из другой страны для сравнения.
